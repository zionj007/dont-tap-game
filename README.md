# DON’T TAP!

A fast reflex game built with Expo. Read the instruction, then decide whether to tap before the timer runs out.

## Included

- Fast tap-or-don’t-tap rounds
- Daily challenge mode
- Local leaderboard
- Cosmetic themes and coin economy
- Tap, correct, and mistake audio feedback

## Run locally

Install dependencies with pnpm, then start the Expo development server:

```bash
pnpm install
pnpm run dev
```

This project is adapted from the Replit DON’T TAP! game artifact into a standalone Expo repository.
